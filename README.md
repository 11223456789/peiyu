# ✨ 佩宇Reader 高级版 - PeiYu Reader Advanced

> 完全原创的沉浸式命令行阅读体验 + AI智能系统

一个基于Python的Legado书源阅读器，采用独特的**佩宇UI设计系统**，融合AI智能推荐、深度阅读分析和游戏化成就系统，提供前所未有的命令行阅读体验。

### 使用TTS语音朗读
```python
from core.tts_engine import TTSEngine
import asyncio

# 初始化TTS引擎
tts = TTSEngine("~/.peiyu_reader")

# 查看可用语音
voices = tts.get_available_voices()
for voice in voices:
    print(f"{voice.voice_id}: {voice.name} - {voice.description}")

# 设置语音
tts.set_voice("zh-CN-XiaoxiaoNeural")
tts.set_speed(1.0)  # 语速

# 合成并播放
async def speak():
    audio_path = await tts.synthesize("你好，这是佩宇Reader的语音朗读功能。")
    tts.play_audio(audio_path)

asyncio.run(speak())
```
